# Why are we banned?

If your server is banned from using Lerche, she will stop reading messages and your server will not be able to use her commands.

A server might be banned because:

- Its name has been flagged as inappropriate or concerning.
- Activity suggests Lerche is being used by people under 18.
- Lerche is being used for harassment, spam, or other harmful content.
- Members are trying to get around an existing restriction or ban.

If you are unsure why you were banned, or think it was a mistake, ask a server administrator to contact the [Lerche help server](https://discord.gg/XMznfREnuH).

Include your server's name and ID, the message you received, and any context that might help explain the situation. You can ask for the ban to be reviewed, but a review does not guarantee that access will be restored.

Reinstalling Lerche will not remove a server ban.
