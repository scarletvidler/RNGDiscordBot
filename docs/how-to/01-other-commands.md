# Other Commands & Things To Know

`/help`

Shows where to find help and support for Lerche.

`/version`

Shows the current Lerche version.

`/info-token-count`

Shows an admin the server's remaining TTS token balance.

If Lerche does not respond to a TTS message, check:

- The message is in the configured TTS text channel, or starts with `/t` when room mode is enabled.
- The user has the `Lerche Listens` role.
- The user is currently in a voice channel.
- Lerche has permission to view, connect to, and speak in that voice channel.
