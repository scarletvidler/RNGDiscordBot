# TTS - Lerche Shutup!

Lerche is a baby bot ... she gets stuck. If she does, or you need to clear the current queue, an admin can use:

`/command-force-stop`

This stops TTS playback, clears the queued messages, and disconnects Lerche in this server.

If Lerche is already speaking in another voice channel, an admin can join the desired channel and use:

`/command-swap-channel`

This moves Lerche to the admin's current voice channel.
