# TTS - How To Use

To make Lerche speak in the normal TTS channel mode:

1. Join a voice channel.
2. Go to the configured TTS text channel.
3. Type your message.
4. Lerche will join your voice channel and read it aloud.

Admins can switch to room mode with:

`/toggle-tts-mode`

In room mode, type `/t` followed by your message in a text channel. Lerche reads it in the voice channel you are currently in.

Example:

`/t Hello everyone!`

Messages must be `300 characters` or less. Mentions and links are cleaned up before being spoken, so Lerche will try to say them in a more natural way.
