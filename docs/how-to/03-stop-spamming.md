# TTS - Lerche, Stop Spamming!

Lerche can post small confirmation messages while handling TTS. She will also show errors sometimes when she encounters a bug or server outage.

Admins can turn confirmation replies on or off with:

`/toggle-tts-confirmations`

Running the command again toggles confirmations back the other way.

Admins can also toggle the jingle that plays before the first TTS message with:

`/toggle-tts-jingle`
