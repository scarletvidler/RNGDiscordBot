Small scope, retained safeguards

Product identity: skus holds catalog names and types; subscription_items retains SKU/title history. login_applications binds database logins to their application.

Access: the private schema, writer/reader roles, RLS, fixed SQL search paths, parameterized calls and verified remote TLS remain. Ordinary clients have no access. Other code still holds a broad Supabase credential in the bot process, so this connection is not full process isolation.

Recovery: startup and periodic list scans repair missed events. A missing row is not a deletion. Catalog reads supply names; no resource fetch independently verifies each event.

Rollout: disabled by default. Apply the follow-up migration through the reviewed migration workflow; it removes the old financial schema objects and columns. Hosted validation and live Discord checks are still required before enabling.
